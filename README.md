# Orchestra Lens · 编排透镜

Luker 多智能体编排（Orchestrator）的可视化工作台。从魔法棒菜单打开，全屏查看编排流程长什么样、每一轮是谁在干活、各自产出了什么。

![流程](docs/screenshots/flow-spec.png)

## 功能

- **流程**：把当前方案画成从左到右的流程图。流水线、单助手、调度、循环、导演五种模式各有布局；同时进行的步骤、审查打回、交给主模型还是直接写回复，一眼能看出来。运行时卡片实时亮起（琥珀色 = 正在工作，青绿 = 完成，红 = 出错）。
- **运行**：泳道时间线，一位助手一行，横条重叠 = 同时进行；点横条看这一段的思考、输出、工具调用和调度决定。运行中可以停止。
- **历史**：自动记下最近 30 次运行的完整过程（只存在本机浏览器），按聊天筛选；更早的楼层显示编排器自己保存的最终结果。
- **详情**：每位助手的职责、角色设定、任务模板、使用的连接配置 / 生成预设、可用工具。
- 顶栏可直接开关编排、切换执行模式，与原生面板同步。明暗主题，电脑与手机布局。
- 快捷键：`1` `2` `3` 切视图，`]` 开关详情栏，`Esc` 逐级退出。

助手的提示词等配置在这里只读，需要修改时点顶栏「在原生面板中编辑」。

![导演模式](docs/screenshots/flow-director.png)

## 安装

1. Luker → 扩展 → 安装扩展
2. 粘贴本仓库地址
3. 刷新页面，确认已启用 **多智能体编排**
4. 魔法棒菜单 → **编排透镜**

## 兼容性

读取 `extension_settings.orchestrator` 和角色卡上的编排方案；运行过程来自编排器的运行面板数据（按 URL 导入 `run-state/store.js`，与编排器共用同一个实例）。在 Luker 2.8.0 上验证。若 Luker 调整了模块路径，界面会提示无法读取数据而不会影响聊天。
